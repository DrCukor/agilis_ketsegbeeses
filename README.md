# 💰 KözösKassza

A **KözösKassza** egy modern, átlátható és könnyen használható asztali alkalmazás, amelyet baráti társaságok, lakótársak közös kiadásainak kezelésére és az egymás közötti tartozások (egyenlegek) igazságos, optimalizált elosztására hoztunk létre.

---

## 🚀 Főbb Funkciók

* **Új kiadás rögzítése:** Megnevezés, összeg, a fizető személy kiválasztása.
* **Dinamikus eloszlás kezelés:** 
  * *Mindenki egyenlően* (automatikus osztás a kijelölt résztvevők között)
  * *Fix összegek (Ft)* (egyéni forint alapú megosztás pontos ellenőrzéssel)
  * *Százalékos arány (%)* (százalékalapú megosztás 100%-os validációval)
* **Tartozások optimalizálása (Egyenlegek):** Kiszámolja, hogy kik között és mekkora összegben rendeződnek a tartozások a legegyszerűbben.
* **Legutóbbi kiadások listája:** Áttekinthető előzmények vizuális jelölésekkel és avatárokkal.

---

## 🛠️ Technológiai Stack

* **Nyelv:** Java
* **UI Keretrendszer:** JavaFX / FXML (modern, reszponzív felépítés)
* **Adatbázis / ORM:** JPA / Hibernate (`BudgetTrackerPU`)
* **Stílus:** Egyedi CSS formázás (`Styles.css`)
